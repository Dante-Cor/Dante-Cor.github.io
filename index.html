Aplicación de teledeteción para estimación de Temperatura de Superficie (LST) con QGIS para Exploración Geotérmica

Este proyecto consistió en la replicación y adaptación de una metodología científica de percepción remota para la identificación de zonas con alto potencial geotérmico en los campos de "La Soledad" (Jalisco) y "Los Negritos" (Michoacán). Se migró el flujo de trabajo original(ArcGIS) a un entorno Open Source (QGIS), procesando imágenes satelitales Landsat 7 ETM+ para generar mapas de Temperatura de la Superficie Terrestre (LST).

Metodología Implementada en QGIS:

Pre-procesamiento y Calibración.

Estimación de Emisividad Superficial.

Recuperación de Temperatura (LST).

Detección de Anomalías.
